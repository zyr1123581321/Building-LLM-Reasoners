# Building LLM Reasoners - Spring 2026

Homework and project work for Greg Durrett's *Building LLM Reasoners* course.
Course page: https://gregdurrett.github.io/courses/sp2026/index.html

## Layout
| Path | Contents |
|------|----------|
| `hw1/` | Assignment 1 (released Jan 23, due Feb 13) |
| `hw2/` | Assignment 2 (released Feb 13, due Mar 6) |
| `hw3/` | Assignment 3 (released Mar 6, due Apr 3; page also says Apr 15 - confirm) |
| `final-project/` | Proposal due Mar 27; presentations May 1 |
| `papers/` | Course readings by week (see `papers/papers.tsv`) |

Each `hwN/` has `docs/` (assignment PDF), `code/`, and `writeup/`.

## Papers
Run `./papers/download.sh` from a machine with arXiv access. Papers with no
arXiv ID are listed in `papers/MANUAL.md`.
